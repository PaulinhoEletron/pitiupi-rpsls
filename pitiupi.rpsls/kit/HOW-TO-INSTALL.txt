RPSLS - Rock, Paper, Scissors, Lizard, Spock
Plugin for Pitiupi (Prof. Flávio, UFSJ)  ·  Author: Paulo Felipe
(Versão em português: COMO-INSTALAR.txt)
=====================================================================

The game is the file  pitiupi.rpsls.jar . It runs inside the professor's
Pitiupi: each player puts the .jar in the plugins folder of THEIR Pitiupi.
Works with any branch of the repository (main, update/mpChat...).
Requires Java 17 or newer.

The game's screens are in Portuguese, like Pitiupi itself.


WHERE THE PLUGINS FOLDER IS
---------------------------
Pitiupi looks for plugins in the  plugins  folder INSIDE the  pitiupi
project (the program), which is inside the cloned repository:

    <cloned repository>/              (git clone .../fls/pitiupi.git)
    ├── pitiupi/                      <- the program (NetBeans project)
    │   ├── src/
    │   ├── dist/pitiupi.jar          <- created when you build
    │   └── plugins/                  <- CREATE this folder (not in git)
    │       └── pitiupi.rpsls.jar     <- PUT the plugin here
    ├── pitiupi.chat/
    ├── pitiupi.mpChat/
    └── pitiupi.screenCast/


1) INSTALL (each player)
------------------------
Linux / macOS:
     cd ~/pitiupi
     mkdir -p pitiupi/plugins
     cp ~/Downloads/pitiupi.rpsls.jar pitiupi/plugins/
     cd pitiupi
     ant jar
     java -Djava.net.preferIPv4Stack=true -jar dist/pitiupi.jar

Windows (Command Prompt):
     cd %USERPROFILE%\pitiupi
     mkdir pitiupi\plugins
     copy %USERPROFILE%\Downloads\pitiupi.rpsls.jar pitiupi\plugins\
     cd pitiupi
     ant jar
     java -Djava.net.preferIPv4Stack=true -jar dist\pitiupi.jar

Notes:
  * "ant jar" builds Pitiupi and is only needed the first time.
    Without ant: in NetBeans, open the "pitiupi" project, Clean and Build,
    then run only the last line (or press Run in NetBeans).
  * Pitiupi MUST be started from inside the "pitiupi" folder: the
    "plugins" path is relative to the working directory. Double-clicking
    the .jar does not work.
  * The console should show:
        Discovered plugin package: pitiupi.rpsls.jar
        [RPSLS] plugin loaded ...


2) PLAY (everyone on the same Wi‑Fi)
------------------------------------
a. Login: EVERYONE uses the same port: 8000.
b. Windows: if the firewall asks, tick "Private networks" AND
   "Public networks" and click Allow (campus Wi‑Fi is usually "public").
c. After a few seconds the other players show up in the "Online" list.
d. Click the other player's name -> Jogos -> Desafiar para RPSLS
   ("Games -> Challenge to RPSLS").
e. They get "E aí, bora jogar...?" ("Let's play?") -> Bora!
f. Countdown 3, 2, 1, Vai! ("Go!") -> each player clicks a move (10 s).
g. Both moves, the rule ("Spock vaporiza Pedra") and the winner are shown.
h. "Jogar de novo?" ("Play again?") -> Yep on both sides = new round;
   Nope ends the match.


3) TROUBLESHOOTING
------------------
* The "Jogos" menu has no RPSLS:
    the .jar is not in <repository>/pitiupi/plugins/, or Pitiupi was not
    started from <repository>/pitiupi, or it was not restarted.

* Nobody shows up in the Online list (the Wi‑Fi blocks multicast):
    - one player:  Jogos -> RPSLS -> Meus endereços IP   (tells the IP)
    - the other:   Jogos -> RPSLS -> Desafiar por IP...  (types the IP)

* "Não foi possível conectar" ("Could not connect"):
    firewall, a port other than 8000, or the Wi‑Fi isolates clients.
    -> use a phone hotspot; turn off VPN, Docker and virtual machines.

* "Convite expirou ... Ele tem o plugin RPSLS instalado?"
  ("Invitation expired ... does he have the plugin?"):
    the other player's .jar is not in the right plugins folder.


4) BUILD THE PLUGIN FROM SOURCE (optional, like the other plugins)
------------------------------------------------------------------
Put the  pitiupi.rpsls/  folder at the repository root (next to
pitiupi.chat/) and:
     cd <repository>/pitiupi.rpsls
     ant jar                       -> dist/pitiupi.rpsls.jar
     mkdir -p ../pitiupi/plugins
     cp dist/pitiupi.rpsls.jar ../pitiupi/plugins/
